## FE-3 · stale banner
- New `<div class="stale" id="stale" role="status" hidden>` under the demo note. Text, e.g. "Newest prices are from Fri 31 Oct. The
  nightly run may have failed; these are screen results for that day, not today." Dashed amber border plus "!" icon, not colour alone.
- Rule: weekdays between latest `asof` of any row and today (browser clock) greater than the limit. Skipped when `DATA.demo`.
- **Q1 limit.** (a) 1 weekday, matches a nightly run, but fires on every Monday morning before 00:15 and on holidays;
  (b) 2 weekdays, quiet on holidays; (c) **recommended:** 2 weekdays, and the text names the date so a reader can judge. The
  pipeline's own skip limit is 4 trading days (CLAUDE.md); the banner should warn earlier than the pipeline drops tickers.
- **Q2 clock.** (a) browser clock, catches an old file opened later (**recommended**; tests fake it with Playwright `page.clock`);
  (b) compare `generated` with `asof`, misses an old file; (c) both, more code for little gain.
- Also: per-region staleness (US vs Europe differ by a day normally), so only the newest `asof` is compared; no per-region banner.
